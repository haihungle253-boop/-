# 中学科二速记

教师资格证「中学科目二·教育知识与能力」复习 App（网页版，可安装到安卓主屏幕）。
内容对照《中学科二系统知识讲义-2026上【肖一点烦】》第1–19页整理，第一章（教育基础）、第二章第一节（课程概述）为完整内容，其余章节已搭好框架，等讲义补充后可继续填充。

## 安装到手机（推荐）

这是一个 PWA（渐进式网页应用），需要先把这个文件夹部署到一个能被手机访问的网址，再"添加到主屏幕"，就会有独立的 App 图标和全屏体验（不显示浏览器地址栏）。

最简单的免费部署方式（任选一个，把整个文件夹拖进去即可）：
- [Netlify Drop](https://app.netlify.com/drop)
- [Cloudflare Pages](https://pages.cloudflare.com/)
- [GitHub Pages](https://pages.github.com/)

部署后用手机 Chrome 打开生成的网址 → 右上角菜单 →"添加到主屏幕/安装应用"。

## 本地预览

不想部署也可以先在电脑上看效果：

```
cd reviewapp
python3 -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000
```

## 功能

- **首页**：按讲义章节浏览，卡片式知识点，还原重要程度（●●●）、考频标签、"小烦口诀"高亮
- **背诵**：把讲义里的口诀做成可翻转的记忆卡片，支持"还没记住/记住了"分组复习
- **自测**：选择题 + 判断题，答错自动进入错题本
- **我的**：复习进度、收藏、错题本、深色/浅色主题

所有数据保存在手机本地（localStorage），不会上传到任何服务器。

## 目录结构

```
index.html              页面入口
css/style.css           样式
js/data.js               讲义知识点数据（可扩充其余章节）
js/quiz.js                自测题库
js/app.js                 页面逻辑
manifest.webmanifest    PWA 配置（图标、名称）
sw.js                     离线缓存
icons/                    App 图标
```

后续章节内容可以直接按 `js/data.js` 里已有的结构补充到对应章节的 `sections` 里。
